# 项目专员端

君实生物"益+同行"院内患者管理 PSP 项目（拓益/特瑞普利单抗）——项目专员端静态原型。

这是一个小程序，与医生端在一起，通过人员角色区分，之前医生端的登录可以复用。

项目专员的职责有：负责现场入组、首周期教育、院内协同、异常回流、周期提醒、标准随访、失访召回、数据质控、周月报输出

纯静态 HTML+CSS+JS，数据全部本地 mock（`js/app.js` 内嵌假数据 + localStorage 存储随访记录）。

## 任务体系（对齐《君实PSP项目随访表单V0.4》9 类任务）

任务列表（task-list.html）支持 9 类筛选 + 状态筛选 + 搜索：

| 任务类型 | 入口页面 |
|---|---|
| 项目说明与授权 | task-detail.html（患者端执行，专员查看） |
| 首触达建档 | followup-form.html?mode=profile |
| 周期治疗/复诊随访 | followup-form.html?mode=cycle |
| 超期未治疗/未复诊召回 | recall-form.html |
| 退出/拒访管理 | withdraw-form.html |
| 异常症状/AE即时随访 | followup-form.html?mode=ae |
| 特殊情形/质量投诉处理 | complaint-list.html |
| PV/事件补充随访 | abnormal-form.html |
| 患者任务-复诊记录 | task-detail.html（查看患者提交） |

## 演示路径

1. **index.html 工作台**：任务统计（待处理/今日到期/AE 待随访）、9 类任务分类入口、今日待办
2. **task-list.html**：9 类筛选 + 状态筛选 + 患者搜索
3. **首触达建档**（任务 t02 林*国）：建档信息确认（系统字段带入）→ 基础疾病与治疗信息 → 治疗计划 → 安全性总筛 → 随访小结
4. **周期随访**（任务 t01 沈*浩）：一般状态 → 复查管理（选"推迟"展开原因题）→ 依从性（选"自行减量"展开原因题；脱落风险选"中/高风险"展开召回举措）→ 安全性总筛选"有" → 展开分类，选"身体不适/症状" → AE 模块展开 → 症状分类选"皮疹" → 勾选"水疱"等紧急线索 → 底部出现醒目红色提示"建议提醒患者尽快就医，并同步项目经理" → 小结提交
5. **AE 即时随访**（任务 t03 曹*云）：顶部展示患者上报的不适描述（来源：患者上报）→ AE 分级问卷 → 提交提示"已生成异常记录，项目经理将跟进"
6. **退出/拒访**（任务 t06 王*华）：退出类型/原因/当次安全性信息（选"有"展开分类+简述）/停止触达确认/必要安全信息渠道/拒访记录 → 提交后患者状态更新为"退出/拒访"
7. **工作纪实**（work-record.html）：查看本地提交的随访记录（含紧急线索标注）
8. 现场入组（enroll-form.html，OCR 识别演示）提交后提示"已生成首触达建档任务"，可直达建档随访

每道题右上角"📖 话术"按钮可查看 V0.4 问卷库对应话术（弹层展示）。

## 安全性总筛交互要点

- Q48 默认展示"未出现"（橙色预选样式），但专员**必须重新点击选项主动确认**后才能提交
- 选"有/不确定"→ 展开安全性信息分类（多选）
- 分类选"身体不适/检查异常/门急诊住院"→ 触发 AE 基础信息与分级模块
- 分类选"妊娠/用药错误/质量问题等"→ 提示按特殊情形/PV 分流处理
- Q9 随访结果选"患者拒绝随访"→ 跳转退出/拒访管理；选"未联系到"→ 直接跳至随访小结
